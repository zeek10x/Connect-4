# Fourward

Fourward is a polished Connect Four game for Android with both pass-and-play two-player mode and a solo mode against a bot. The bot recognizes immediate wins and blocks, while round scoring, win detection, draws, and quick restarts keep games moving.

## Run in Android Studio

1. Open this `connect_four` folder in Android Studio.
2. Confirm the Flutter and Dart plugins are enabled.
3. Choose an Android emulator or connected phone.
4. Run `lib/main.dart`.

Or run from a terminal:

```sh
flutter pub get
flutter run
```
